1. Problem statement

Build and compare five classifiers (Logistic Regression, Decision Tree, kNN, Naive Bayes, Random Forest) on one public dataset and evaluate them with Accuracy, AUC, Precision, Recall, F1 and MCC. The task is binary classification: predict whether yearly income is above 50K USD ('>50K') from census attributes.

2. Dataset description

  • Source: UCI Adult Census Income, loaded via OpenML (data id 1590)
  • Instances: 48,842 rows (48,790 after removing 52 duplicates) | Features: 14 | Target: class (<=50K, >50K)
  • Class distribution: <=50K: 37,155 (76.07%), >50K: 11,687 (23.93%) (imbalance 3.18:1)
  • Missing values: 6465 cells in 3 columns, imputed inside the pipeline.
Feature type Count Features
Numeric 6 age, fnlwgt, education-num, capital-gain, capital-loss, hours-per-week
Categorical 8 workclass, education, marital-status, occupation, relationship, race, sex, native-country

Preprocessing: duplicates removed; median / most-frequent imputation; one-hot encoding; standard scaling; stratified 80:20 split with seed 42; all steps fitted on the training data only (scikit-learn Pipeline).

4. Observations

ML Model NameObservation about model performance
Logistic RegressionAccuracy 0.848, AUC 0.902, F1 0.648, MCC 0.557 (rank 3 of 5 by MCC). Precision (0.726) is higher than recall (0.585), so it is cautious about predicting '>50K' and misses some true cases. Training accuracy (0.846) is close to test accuracy, so it generalises well. It learns one linear decision boundary on the scaled and one-hot encoded features, so it is fast and stable but cannot capture feature interactions.
Decision TreeAccuracy 0.851, AUC 0.902, F1 0.642, MCC 0.561 (rank 2 of 5 by MCC). Precision (0.756) is higher than recall (0.558), so it is cautious about predicting '>50K' and misses some true cases. Training accuracy (0.862) is close to test accuracy, so it generalises well. A single tree (depth limited to 8) captures non-linear rules and interactions and is easy to interpret, but one tree is high-variance and sensitive to the training sample.
kNNAccuracy 0.835, AUC 0.884, F1 0.635, MCC 0.531 (rank 4 of 5 by MCC). Precision (0.675) is higher than recall (0.601), so it is cautious about predicting '>50K' and misses some true cases. Training accuracy (1.000) is clearly above test accuracy, which indicates overfitting. It classifies by the 15 nearest training points, so it depends on feature scaling and loses discriminative power in a high-dimensional one-hot space; it also has to compare every test row with all training rows at prediction time.
Naive BayesAccuracy 0.617, AUC 0.833, F1 0.536, MCC 0.385 (rank 5 of 5 by MCC). Recall (0.924) is higher than precision (0.378), so it finds most '>50K' cases but with more false alarms. Training accuracy (0.619) is close to test accuracy, so it generalises well. Gaussian Naive Bayes assumes independent, normally distributed features; one-hot columns are neither, so its probability estimates are often less reliable than those of the other models.
Random Forest (Ensemble)Accuracy 0.863, AUC 0.916, F1 0.683, MCC 0.603 (rank 1 of 5 by MCC). Precision (0.768) is higher than recall (0.614), so it is cautious about predicting '>50K' and misses some true cases. Training accuracy (0.902) is close to test accuracy, so it generalises well. Averaging 300 decorrelated trees reduces the variance of a single tree and captures non-linear interactions, which typically gives the most robust results on tabular data.

Overall winner for this dataset: Random Forest (Ensemble) is the overall winner on this dataset: it ranks first by MCC (0.603, AUC 0.916) and is the best model on 5 of 6 metrics; the runner-up is Decision Tree (MCC 0.561). Because the classes are imbalanced (23.9% minority class), accuracy alone is optimistic, so MCC and AUC were used as the main criteria.
